SOLDIER 2.0
===========

A puzzle game: lead the soldier through 51 levels of walls, boxes, buttons, doors,
coloured keys, guillotines and water to the exit. A remake of Soldier 1.1 (QBasic, 2000):
the levels and the rules are the original ones, the presentation is new.

Run soldier.exe. The map editor is soldier_editor.exe, the graphics editor is painter.exe
(see PAINTER.txt).

GAME CONTROLS
  Arrows            step / turn
  , <   and   . >   turn counter-clockwise / clockwise
  Tab               select the next key in the inventory
  Space / Enter     use the selected key (put it in front of you or open the door in front)
  Esc               give up the level
  P                 pause
  Z                 zoom 2x / 1x
  F11 / Alt+Enter   fullscreen

MENU
  Up / Down         menu item;  Tab / Left / Right: select a player
  Enter / Space     choose;     Esc: exit
  NEW GAME, REPLAY LEVEL (watch your best run; 1 / 2 / 4 or Tab: replay speed),
  DELETE PLAYER, OPTIONS (game speed, sound, music, fullscreen), EXIT.

MAP EDITOR (soldier_editor.exe)
  Tab: field <-> palette, arrows: cursor, Space / Enter: place, Backspace: erase,
  mouse: left places, right erases, wheel zooms, middle button pans,
  Ctrl+Z / Ctrl+Y: undo / redo, Ctrl+N / O / S: new / open / save,
  F5: test-play the level in soldier.exe, Esc: quit.

SAVES
  Players, records and settings: %APPDATA%\V Software\Soldier
