# Keyboard Simulator — the application

`keyboard_simulator.exe` (CMake target `keyboard-simulator`): the touch-typing trainer, a remake of
the 2007 thesis program. One resizable window (logical canvas 1280×720, letterboxed), Russian UI,
light flat design with PT Sans / PT Mono. Logic lives in `keyboard-simulator/core` (`kbsim_core`);
this folder contains only the SDL front end on `vs_engine`.

## Screen

- **Text card** (top left): the current sentence and the next one (dimmed), word-wrapped by the
  measured width of PT Mono. The typed part is green, the letter to type sits in a cursor box that
  glides from letter to letter; a wrong press shakes the box and flashes it red. After the last
  character the sentence leaves and the text glides up.
- **Stats bar** (bottom of the text card): «Скорость: N зн/мин», «Ошибки: N», «Точность: N%»,
  «Время: mm:ss». The clock starts with the first key press and stops while paused.
- **Buttons** (right): «Рестарт», «Пауза» / «Продолжить», «Помощь», «О программе», each with its
  hotkey chip; below them the "next key" card (the character, the finger, the Shift to hold,
  sentences and characters typed) and the sound switch.
- **Keyboard** (bottom): ЙЦУКЕН from `data/layout/ru.json`, keys tinted by finger with the
  original's colour logic (green, yellow, lavender, pink, cyan, grey), shifted symbols small at the
  top left, bumps on А and О. The key to press glows (and the Shift of the other hand for capitals
  and shifted symbols); a correctly pressed key sinks briefly; a wrong key flashes red. The finger
  legend «5 4 3 2 1 / 1 2 3 4 5» below highlights the finger to use (thumbs = both 1s).

## Controls

| Key / action | Effect |
|---|---|
| typing (Russian layout) | input by the actual character (SDL text input) |
| F2 / «Рестарт» | new sentences, statistics reset |
| F3, Pause / «Пауза» | pause / resume (the clock stops, the text is blurred) |
| F1 / «Помощь» | help on touch typing and the trainer |
| F4 / «О программе» | about |
| F5 / «Звук» | sound on/off (saved) |
| Esc | closes a dialog; on the main screen asks whether to quit |
| Enter, ←/→, Tab | dialog buttons |
| F11, Alt+Enter | fullscreen (engine) |

Opening a dialog or losing window focus pauses a running exercise; closing the dialog resumes it.
Closing the window (title bar ×, Alt+F4) asks «Выйти из тренажёра?» like Esc (not in `--smoke` and
scripted runs).
If a Latin letter is typed, a hint asks to switch the keyboard layout to Russian.

Settings: `%APPDATA%\V Software\Keyboard Simulator\settings.json` (`{"sound": true}`), or
`<path>/settings.json` with `--data-dir <path>`. `--smoke` and scripted runs (`--screenshot`,
`--autotype`, `--type`, `--state`) without `--data-dir` use a temporary folder
(`%TEMP%\vs-smoke\Keyboard Simulator`) and never create anything in `%APPDATA%`.

## Command line

| Flag | Meaning |
|---|---|
| `--smoke`, `--windowed`, `--fullscreen` | engine flags (`--smoke`: run one second, exit 0) |
| `--data-dir <path>` | engine flag: keep the settings in `<path>` instead of `%APPDATA%` |
| `--screenshot <png>` | render, save the frame as PNG and quit |
| `--autotype <n>` | type the first n expected characters correctly |
| `--type "<utf8>"` | then type this text verbatim (wrong characters count as errors) |
| `--state paused\|help\|about\|quit` | then open this state |
| `--seed <n>` | fixed sentence order |

Scripted runs use a virtual clock driven by the fixed logic step, so screenshots are reproducible.

```sh
# Git Bash, no visible window, no sound card
SDL_VIDEO_DRIVER=offscreen SDL_AUDIO_DRIVER=dummy build/kbsim-app/bin/Debug/KeyboardSimulator/keyboard_simulator.exe --smoke
SDL_VIDEO_DRIVER=offscreen SDL_AUDIO_DRIVER=dummy build/kbsim-app/bin/Debug/KeyboardSimulator/keyboard_simulator.exe \
    --seed 7 --autotype 30 --type "ы" --screenshot shot.png
```

## Source files (`src/`)

| File | What |
|---|---|
| `main.cpp` | config, window icon (`vs::set_window_icon` with `gfx/icon*.png`), scene |
| `trainer_scene.*` | the screen: layout, input, typing, pause, dialogs, debug script |
| `text_view.*` | sentences, cursor box, scroll animation, paused blur |
| `stats_bar.*` | the four statistics |
| `keyboard_view.*` | on-screen keyboard, highlights, animations, finger legend |
| `side_panel.*` | buttons, next-key card, sound switch |
| `modal.*`, `dialogs.*` | modal card and the Help / About / quit contents |
| `palette.*` | theme colours, finger colours and names |
| `fonts.*`, `sounds.*`, `settings.*` | resources and settings |
| `draw_util.*` | shadows, glow, colour helpers, UTF-32 → UTF-8 |
| `options.*` | command line (the screenshot itself is `vs::save_frame_png`) |

## Build

```
cmake --preset vs2022 -B build/kbsim-app
cmake --build build/kbsim-app --config Release --target keyboard-simulator
```

The executable embeds `res/app.ico` (`res/app.rc`; generated by `tools/assets/gen_icons.py`).
