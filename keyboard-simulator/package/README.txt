KEYBOARD SIMULATOR 2.0
======================

A touch-typing trainer for the Russian (ЙЦУКЕН) layout. A remake of the 2007 thesis
program "Клавиатурный симулятор слепой печати". The interface is in Russian.

Run keyboard_simulator.exe and switch the keyboard layout to Russian. Type the highlighted
letter; the on-screen keyboard shows the key and the finger to use (and the Shift of the
other hand for capitals). Speed (characters per minute), errors and accuracy are shown
below the text.

CONTROLS
  F2                Restart (new sentences, statistics reset)
  F3 / Pause        pause / resume
  F1                help
  F4                about
  F5                sound on / off
  Esc               close a dialog; on the main screen: quit
  F11 / Alt+Enter   fullscreen

SETTINGS
  %APPDATA%\V Software\Keyboard Simulator\settings.json
