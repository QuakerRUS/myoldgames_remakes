# Keyboard Simulator: sentence file (`keyboard-simulator/data/texts/ru.txt`)

The sentences the user types, taken unchanged from the 2007 program.

- UTF-8 without BOM, LF line endings, a final newline.
- One sentence per line; every line ends with `.`, `!` or `?`; no leading, trailing or
  double spaces.
- 5630 sentences, 295 634 characters (5616 distinct: 14 lines repeat earlier ones). Alphabet: space,
  `! " ( ) + , - . 0–9 : ; ?`, А–Я without Ё, Ъ and Ь, а–я without ё. Every character is on
  the layout (`kbsim-layout.md`); the core tests check it.

Generated by `python -I tools/import/kbsim_texts.py` from
`archive/diplom-2007/program/Data/Texts/text_rus.txt` (CP866, CRLF; the last line has no
line break, which is why counting line breaks gives 5629). The only change: one Latin `c`
inside a Russian word ("cрочно", line 2631) is replaced with the Cyrillic `с`; the script
fixes any Latin look-alike letter the same way and fails on any other Latin letter.

`kbsim::TextSource::load` also accepts CRLF and skips empty lines.
