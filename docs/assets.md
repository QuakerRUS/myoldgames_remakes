# Assets: inventory, provenance and licences

This file is for our own records. The games never credit asset sources (see the design spec).
Every asset is either **generated by our own code** in `tools/assets/` (our own work, same licence as
the repository) or is a font under the **SIL Open Font License 1.1** from
[github.com/google/fonts](https://github.com/google/fonts). No third-party images, samples or music are used.

## Regenerating

```
python -I tools/assets/build_all.py            # everything (fonts, branding, gfx, sfx, music)
python -I tools/assets/build_all.py --preview  # + contact sheets into the scratch preview dir
```

`build_all.py` needs Pillow, numpy, scipy and soundfile. If the running interpreter does not have them, it
re-runs itself with `.venv` (created on demand: `python -m venv .venv` + `pip install pillow numpy scipy soundfile`).
`.venv/` must stay out of git. All generators use fixed seeds; two consecutive builds were verified to be
byte-identical (80 output files, md5). Outputs are committed.

## Sprite sheet format

Engine format (`engine/src/sprite_sheet_data.cpp`): `{"image", "frames": {name: {x,y,w,h[,pivot_x,pivot_y]}},
"animations": {name: {"frames": [...], "ms": N, "loop": bool}}}`. Animations with per-frame durations
use `"frames": [{"frame": name, "ms": N}, ...]`. A pivot is the point of the frame put on the draw position;
frames taller than a cell have `pivot_y` = extra height, so they are drawn at the cell's top-left corner.
Frames are separated by a 1 px transparent gap.

## Soldier — `soldier/data/gfx/` (own work, pixel art, one fixed palette in `soldier_pal.py`, ~80 colours)

Light comes from the top-left; objects drop shadows down-right; 3/4 top-down view; 32×32 cells drawn 1:1.

## Sounds (own work, synthesized with numpy in `gen_sfx.py`; WAV 44.1 kHz 16-bit mono, peak ≤ −1 dBFS)

Each sound has its own fixed seed (11–63). Frequent sounds are mixed quieter (×0.4–0.55).

- `soldier/data/sfx/`: `step`, `step_2` (alternate foot), `turn`, `push_box`, `box_sink`, `button_press`,
  `button_release`, `door_open`, `door_close`, `key_pickup`, `key_drop`, `door_unlock` (coloured door),
  `wall_reveal` (dark wall), `guillotine_chop`, `drown`, `death`, `give_up` (fuse beeps + explosion),
  `timer_tick` (last 15 units), `level_win`, `menu_move`, `menu_select`, `error` (denied).
- `piton/data/sfx/`: `eat`, `turn`, `die`, `level_complete`, `menu_move`, `menu_select`.
- `keyboard-simulator/data/sfx/`: `key_correct` (soft click), `key_wrong` (soft buzz), `sentence_complete`
  (chime), `button_click`.
