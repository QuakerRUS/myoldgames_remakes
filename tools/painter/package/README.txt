PAINTER
=======

The pixel-art editor of Soldier 2.0 and Piton: PNG images and sprite sheets (a PNG plus a
JSON file with frames and animations), in the spirit of PAINTER2 (2000).

Run painter.exe, or drop a .png / .json file on it.

KEYBOARD MODE (as in PAINTER2)
  Tab               canvas <-> palette
  Arrows            move the cursor (Shift: 8 pixels) / the palette selection
  Space / Enter     paint the foreground colour (palette: take the colour)
  Backspace         paint the background colour
  Delete            erase to transparent
  F1                flood fill from the cursor
  Esc               cancel / deselect / quit

TOOLS
  B pencil, E eraser, G fill, L line, R rectangle (Shift+R filled), I picker,
  M select, T frame rectangle, Y pivot, X swap colours, Shift+H / Shift+V flip,
  F frame view, [ ] previous / next frame, O onion skin, P play the animation,
  + / - / Home zoom, Ctrl+C / X / V copy / cut / paste, Ctrl+Z / Ctrl+Y undo / redo,
  Ctrl+N / O / S new / open / save.
  Mouse: left / right button paint with the foreground / background colour,
  Alt+click picks a colour, wheel zooms, middle button (or Space + drag) pans.
